## 洛杉矶 CMIN2 VPS 到底是什么

先把“CMIN2 VPS”这个词拆开。

CMIN2 是中国移动国际网络中的一条专门用于优化中国方向访问的网络。DMIT 目前没有把它单独做成一个叫“CMIN2”的产品系列，而是把 CMIN2 放进 **Eyeball Network** 的网络策略里。官方当前页面明确写到，Eyeball Network 是 Tier 1 transit 配合 CMIN2 等中国 Eyeball 运营商的合理努力路由，目标是在成本与中国大陆访问质量之间取得平衡。

因此，看到“DMIT CMIN2 VPS”时，更准确的产品对应关系是：

> **洛杉矶节点 + Eyeball Network + LAX EB 系列。**

这也解释了为什么很多旧文章直接把 **LAX.EB = CMIN2**。产品定位本身没有完全错，但现在更严谨的说法应该是：LAX.EB 属于 DMIT 的 Eyeball 网络，官方说明其中包含 CMIN2 路由，而且具体路径会根据网络状态调整。

### 三网都走 CMIN2 吗？

这里最容易被营销标题带偏。

公开测评资料对 LAX.EB 的典型观察是：移动方向使用 AS58807/CMIN2，联通方向通常涉及 AS9929，而电信方向存在 AS9929 与 AS58807 的组合或负载均衡。2025 年的更新测评也记录过这种路由结构。

但不要把这理解成“永远固定三网同一路由”。DMIT 自己的 NOC 近期记录显示，LAX.Pro 曾因为中国移动 CMIN2 方向的丢包问题临时改变入站策略，而 **LAX.EB 当时仍维持 CMIN2 入站**，直到相关丢包达到不可接受程度。另有运营记录提到 AS58807 在中美骨干方向存在容量压力。

这反而是选择洛杉矶CMIN2 VPS时最值得记住的一句话：

**CMIN2 是线路能力，不是固定不变的性能保证。**

你的本地运营商、访问目的地、时间段以及当时的路由状态，都会影响最终体验。

## TINY、Pocket、STARTER 到底怎么区分

对于普通个人用户，没必要为了“10Gbps”三个字一路买到最高配。

### TINY：更像线路体验入口

TINY 是 1 核 2GB、20GB SSD、1500GB 流量、2Gbps 端口，价格 **$10.90/月**。

如果你的用途是轻量网站、反向代理、远程管理、开发测试或者单纯想验证某条线路，这一档已经足够判断“洛杉矶 + CMIN2/9929 组合是不是适合自己”。

它的限制也很明显：CPU 只有 1 vCore，存储只有 20GB。拿它做大型数据库、编译节点或者高并发应用，就不是线路问题，而是计算资源本身不够。

### Pocket：多一点 CPU 和磁盘

Pocket 增加到 2 vCPU、40GB SSD、3000GB 流量和 4Gbps 端口，月付 **$16.90**。

这个级别比较适合已经明确需要长期跑服务，但 CPU 和存储负载并不高的人。相比 TINY，它不是简单“贵 6 美元”，而是 CPU、磁盘和流量同时增加了一档。

### STARTER：配置开始比较宽松

STARTER 是 2 vCPU、2GB RAM、80GB SSD、5000GB 流量和 10Gbps 端口，月付 **$34.90**。

这里有一个容易误解的点：**10Gbps 端口不代表你的 VPS 一定能跑满 10Gbps。** DMIT 对虚拟网卡峰值本身就注明，实际互联网速度还取决于虚拟机性能、国际网络和本地网络环境。

所以 STARTER 更适合“流量需求明显上升，但计算负载还没有很高”的网站、API、下载节点和跨境业务应用。

## MINI 与 MICRO：价格差主要买什么

MINI 是 4 vCPU、4GB RAM、80GB SSD、10TB 流量，**$62.90/月**；MICRO 同样是 4 vCPU、4GB RAM，但 SSD 增加到 160GB、流量增加到 14TB，价格 **$87.90/月**。

所以这里没有什么复杂的选择题。

如果 CPU 和内存已经够用，只是网站图片、容器镜像、日志、缓存越来越占空间，MICRO 的升级价值主要就在 **额外存储和流量**。

反过来，如果实际服务每天消耗的流量很低，MINI 不一定需要升级。VPS 最容易出现的浪费，就是为了“以后可能用得到”提前买大量配置。

### MEDIUM：面向更重的业务

MEDIUM 提供 6 vCPU、8GB RAM、160GB SSD、30000GB 流量以及 10Gbps 端口，当前公开月付价格为 **$199.90**。

这个价格已经明显进入高配区间。如果你的项目只是个人站点或轻量代理服务，通常没有必要因为“CMIN2”三个字直接跳到这个级别。

真正需要考虑 MEDIUM 的，是计算、内存或流量已经有明确的实际需求，例如更重的应用后端、数据库、编译任务或者较大规模的内容传输。

## 洛杉矶 CMIN2 VPS 与 CN2 GIA 怎么理解

DMIT 当前把 Premium 和 Eyeball 两条路线明确区分开。

Premium Network 使用 CN2 GIA，并将其定位为面向中国大陆用户的低延迟、低丢包网络；Eyeball 则是 Tier 1 加上 CMIN2 等中国运营商的尽力路由。

因此可以把两者理解成两种不同的购买逻辑：

| 关注点 | LAX.EB / Eyeball | LAX.Pro / Premium |
| --- | --- | --- |
| 核心网络方向 | CMIN2 等中国 Eyeball 网络 | CN2 GIA |
| 中国移动关注度 | 高 | 也可用，但路线逻辑不同 |
| 中国大陆路由保障 | Best-effort / 尽力路由 | Premium 路由 |
| 价格定位 | 相对偏成本平衡 | 更偏高质量中国方向 |
| 适合场景 | 兼顾中国用户的全球业务 | 更重视中国大陆访问体验的业务 |

注意，**这里不是在说哪条线路“永远更快”**。DMIT 当前自己的产品定义已经说明两者的网络目标不同，而且真实路径会发生变化。选择线路时，与其背诵“电信一定怎样、移动一定怎样”，不如用实际运营商线路做 Looking Glass 或路由测试。

## 还有几个购买前容易忽略的限制

### 1. 流量用完后的处理要看具体套餐规则

DMIT 的历史 LAX.EB 活动页说明，流量额度每月重置，额度耗尽后端口会按产品规则严格限速，而不是继续无限速使用。活动页面也明确说明峰值 VirtIO 带宽只是理论接口速率，不是现实互联网吞吐承诺。

因此不要看到 10Gbps 就把它理解成“每月可以稳定下载 30TB，还能一直跑满”。

### 2. IP 不是“美国 IP 解锁保证书”

DMIT 当前 IP FAQ 明确表示，分配的 IP 并不保证特定地理位置，也不保证访问 Netflix、ChatGPT、游戏或其他指定服务。Premium 与 Eyeball 实例可以针对首次连接可达性提出处理，但这和“保证某个平台解锁”是两回事。

这点非常重要。很多旧测评会展示某个时点的流媒体测试结果，那只能说明**当时那个 IP 的状态**，不能作为今天购买后必然得到相同结果的承诺。

### 3. IP 更换有规则

DMIT 当前政策对 Pro 与 EB 系列提供有限的免费 IP 更换机制。一般要求实例已经购买至少 7 天，距离上次 IP 更换至少 15 天，同时服务剩余有效期至少 7 天；符合条件后可申请免费更换。

这对 VPS 用户比较实用，但也不要理解成“IP 不满意就随时免费换”。

### 4. 退款不是无条件试用

DMIT 当前退款文档写得比较明确：新服务购买不超过 3 天、VM 流量使用不超过 30GB，可以申请全额退款；30 天内则存在按剩余价值计算的部分退款规则，同时还有次数及其他限制。

因此实际测试时，最好先做基础的路由、延迟、丢包和业务可用性检查，不要一上来就把几十 GB 的数据跑掉。

所以阅读“洛杉矶CMIN2 VPS 测评”时，最值得看的不是一句“稳不稳”，而是：

* 测试日期是什么时候；
* 测试使用的是 Pro 还是 EB；
* 测试时本地网络属于电信、联通还是移动；
* 测的是去程还是回程；
* 有没有晚高峰数据；
* 测试 IP 到现在是否已经变化。
